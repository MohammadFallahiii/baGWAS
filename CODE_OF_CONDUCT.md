# Code of Conduct

## Our standards

Contributors are expected to communicate respectfully and constructively. Harassment, discrimination, personal attacks, and deliberately disruptive behavior are not acceptable.

## Scope

This code of conduct applies to repository issues, pull requests, discussions, and other project-maintained spaces.

## Enforcement

Project maintainers may remove comments, close discussions, or restrict participation when conduct violates these standards. For concerns, contact a project maintainer through the repository contact information.
